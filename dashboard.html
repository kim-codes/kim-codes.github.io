Program Pulse
Reading a program's vitals

I built Program Pulse to explore how I would turn program data into a clearer view of program health.
Bringing together pipeline, progression, risk, and performance signals in one place.

Along the way, I used AI as part of the toolkit to help shape the analysis and build the experience.

What we did

The dashboard isn't meant to reproduce the source data.
It's organized around the questions a program owner actually needs to answer:

  • How much pipeline do we have?
  • Where are we above or below expectations?
  • Where is it progressing or getting stuck?
  • What needs attention?
  • Which regions, products, or industries are performing differently?
